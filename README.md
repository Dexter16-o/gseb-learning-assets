# gseb-learning-assets

Public textbook assets for the Rasayan GSEB learning app.

- `textbook-pages-v1/`: 172 progressive JPEG page previews rendered at 120 DPI from the source textbook. The app loads only the selected page for a faster reading experience.
- The original full-resolution textbook PDF is available from the [`textbook-v1` release](https://github.com/Dexter16-o/gseb-learning-assets/releases/download/textbook-v1/chemistry-part1.pdf).

The page previews are convenience images; use the original PDF when you need full-resolution zooming or printing.
